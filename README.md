# windscout-privacy

Publishes the Windscout privacy policy at a public URL via GitHub Pages, for the
App Store / Play Store privacy-label forms (which require a live link, not a file).

Source of truth for the policy text is `PRIVACY.md` in the main
[windscout](https://github.com/joelaskling/windscout) repo — `index.md` here is a manual
copy. If the policy changes there, copy it here too and push.
